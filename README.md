# Netflix-Movies-TV-Shows-Analysis

## Objective
Analyze the Netflix dataset to discover trends and insights about movies and TV shows.

## Dataset
Netflix Advanced Dataset (CSV) downloaded from Kaggle.

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Power BI

## Project Steps
1. Imported the dataset.
2. Cleaned and prepared the data.
3. Performed exploratory data analysis.
4. Created visualizations.
5. Built an interactive Power BI dashboard.

## Dashboard
The dashboard includes insights such as:
- Movies vs TV Shows
- Content by Genre
- Content by Country
- Release Year Trends
- Ratings Distribution
